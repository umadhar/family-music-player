# Roadmap

## Phase 1 — complete MVP

- local audio import from Android storage
- library search and playback queue
- playlist creation and favorites
- SQLite persistence
- colorful Material 3 interface

## Phase 2 — networked music management

- server-side catalog and user management
- web admin uploads and metadata review
- secure file storage and signed URLs or authenticated streaming
- Android app browsing of remote catalog and offline caching

## Phase 3 — polish and reliability

- background playback with notifications and media controls
- advanced metadata reading
- resilient sync and retry logic
- optional sharing, import cleanup, and library re-indexing
